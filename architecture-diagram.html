Ingestion & Enrichment Layer
🔍
Symbol Extractor
Parses diff to find changed functions, classes, methods across all languages. Ranks by blast radius.
🕸
Reference Finder
Finds every caller of changed symbols.
auto_clone → shallow git clone + grep
local_grep → REPO_LOCAL_PATH
diff_scan → within PR diff
🛡
OSV Client
Real-time CVE lookup via OSV.dev API for changed dependencies. Maps packages to known vulnerabilities.
🗺
Service Graph Builder
Constructs service dependency graph. Identifies which downstream services are exposed to the change.
📚
Language Registry
Detects language, framework, and file type per hunk. Routes to appropriate parsers.
↓ enriched analysis request
